## Tokens de diseño (Figma)

### Colores

| Token | Valor | Uso |
|---|---|---|
| `--color-bg` | `#020202` | Fondo general |
| `--color-surface` | `#1B1B1B` | Superficies (badge, pills oscuras) |
| `--color-accent` | `#FFCC00` | Acento (botones, highlight) |
| `--color-text` | `#FFFFFF` | Texto principal (Nero) |
| `--color-text-muted` | `#D9D9D9` | Texto secundario, divisores (Alto) |
| `--color-text-on-accent` | `#07080A` | Texto sobre acento |
| `--color-white-plateau` | `#e7eaee` | Reserva del style.md original |

### Tipografías

| Token | Fuente | Uso |
|---|---|---|
| `--font-heading` | League Spartan | Títulos (hero, secciones, CTA) |
| `--font-body` | Inter | Cuerpo, cards, footer |

### Radios y espaciados

| Token | Valor | Uso |
|---|---|---|

| `--section-gap` | `6rem` | Separación entre secciones |
